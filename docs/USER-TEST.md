# 使用者測試腳本

對應企劃書第八節的 H1～H7。每位受測者約 30～40 分鐘，建議兩位組員一起：一位帶流程，一位觀察和操作研究模式面板。

## 事前準備（每台電腦一次）

1. 用 **Chrome** 打開 `https://lalyuns.github.io/photo-select/?research=1`
   - 左下角出現「研究模式」就對了。這個開關只對這個分頁有效，受測者自己打開網址不會看到
2. 產生測試照片（在專案資料夾執行）：
   ```bash
   npm run test-data -- ~/Desktop/照片篩選器測試 300
   ```
   會產生 `手機/`、`相機B/`、`H1-100張/` 三個資料夾
3. 在桌面另外建一個空資料夾「整理結果」
4. 研究模式面板 →「清除紀錄」，從乾淨的狀態開始

## 每位受測者開始前

1. 研究模式面板填**受測者代號**（P01、P02…），不要填真名
2. 說明：「照片只在這台電腦處理，不會上傳。我們測的是工具，不是你。」
3. 徵得同意後才錄影或錄音

## 測試流程

### 任務 1：Finder 整理 100 張（H1 對照組）

- 給受測者 `H1-100張` 資料夾，請他用 Finder 分成「保留／刪除／待考慮」三個資料夾
- **用碼錶計時**，記在下方表格
- 一半受測者先做任務 1，另一半先做任務 2，避免「第二次比較熟」影響結果

### 任務 2：照片篩選器整理同一組 100 張（H1、H2、H5）

- 打開網頁，**不給任何說明**，請受測者「用這個工具整理 H1-100張」
- 觀察並記錄：
  - Chrome 跳出授權視窗時，受測者有沒有猶豫、問問題、或想按取消 → 有的話按面板「授權時猶豫」（H5）
  - 首次設定分類花多久、卡在哪裡（H2，紀錄會自動算 `setupSeconds`）
  - 有沒有一直看下方的按鍵提示或按「說明」（H2，紀錄會自動算前後半段次數）
  - 有沒有說「這張想放兩個分類」→ 按面板「想放進兩個分類」（H4）
- 整理完請他歸檔到桌面的「整理結果」

### 任務 3：自訂分類（H2、H7）

- 給 `手機` 資料夾，請他依自己的需要新增 2～3 個分類（例如「朋友」「風景」），整理 50 張以上
- 觀察：建了自訂分類後還會不會按「保留」（H7，紀錄會自動算 `keepUsesWithCustom`）
- `手機` 資料夾裡有一張壞掉的照片和一些 HEIC／RAW，觀察受測者看到提示時的反應

### 任務 4：事後訪談（H3、H6）

1. 「歸檔是複製一份，原本的照片還在。你覺得可以嗎？還是希望直接搬過去？」
   - 想搬移或想刪原檔 → 按面板「想搬移／想刪原檔」（H3）
2. 請受測者打開**自己手機或相機最近要整理的資料夾**，看一下有多少 HEIC、RAW（H6）
   - 用照片篩選器選那個資料夾，設定畫面會顯示「另有 HEIC N 個暫不支援」，紀錄也會自動記下。看完直接按返回，不用整理
3. 開放問題：最不順的地方是哪裡？

### 結束

研究模式面板 →「匯出 JSON」，檔名會是 `photo-select-P01-日期.json`，上傳到組內共用資料夾。

## 判斷標準（企劃書第八節）

| 假設 | 看 JSON 的哪個欄位 | 成立的條件 |
|---|---|---|
| H1 鍵盤分類比 Finder 省時 | `sessions[].sortSeconds`（100 張那一輪）對照紀錄表的 Finder 用時 | 原型用時少一半以上 |
| H2 能自行設定並記住按鍵 | `setupSeconds`、`helpOpensFirstHalf` → `helpOpensSecondHalf` | 3 分鐘（180 秒）內設定完成；後半段查看次數比前半段少 |
| H3 複製可被接受 | `notes["H3-想搬移"]` | 多數仍想搬移 → 加入「直接搬移」選項 |
| H4 一張只歸一類就夠 | `notes["H4-想放兩類"]` | 超過三分之一受測者遇到 → 支援多分類 |
| H5 願意授權 | `pickers[]` 裡 `granted` 的比例、`notes["H5-猶豫授權"]` | 九成以上願意授權 |
| H6 只支援 JPEG／PNG 夠用 | `unsupported`（受測者自己的資料夾那一輪） | HEIC 或 RAW 占多數 → 提前支援 |
| H7 有自訂分類後「保留」可以移除 | `customCategoryCount` > 0 時的 `keepUsesWithCustom` | 很少使用 → 預設隱藏 |

### 欄位說明

- `sortSeconds`：實際在分類的時間。兩次分類之間隔超過 60 秒（休息、離開）只算 60 秒
- `resumed`：中途關掉又接續了幾次。接續的部分會算在同一輪
- 紀錄裡**沒有檔名和資料夾名稱**，只有張數、順序、時間和分類名稱
